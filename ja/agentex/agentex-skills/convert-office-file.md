# Officeファイル変換 (Word/Excel/PowerPoint)

## When to Use

- ユーザーが手持ちの `.docx`, `.xlsx`, `.pptx` ファイルの内容をMarkdown、テキスト、またはCSV/JSON形式に変換し、VFS上に保存したり表示したりしたいとき。
- バイナリのOfficeファイルから文章や表データを抽出して、Geminiが処理しやすい形式に変換するとき.

## Process

1. **入力ファイルの受け取りと検証**
   1. ユーザーから対象のOfficeファイル（Word, Excel, PowerPoint）を受け取る（チャットでアップロード、またはdrive/フォルダー内のリンク）。
   2. ファイルの拡張子を確認し、対応するOffice形式（`.docx`, `.xlsx`, `.pptx`）であることを検証する。
   3. 古い形式（`.doc`, `.xls`, `.ppt`）の場合は「旧形式のため変換精度が低下する可能性があります」と注意喚起する。
   4. **フォールバック**: ファイルが破損して開けない場合、「ファイルが破損している可能性があります。再度アップロードするか、別のバージョンを試してください」と案内する。

2. **ドキュメントタイプの判定と変換**
   1. ドキュメントのタイプに応じて、以下の規則でテキスト化を行う：
      - **Word (.docx)**:
        1. 見出し（Heading 1, 2, 3）をMarkdownの `#`, `##`, `###` にマッピングする。
        2. 段落、リスト（番号付き・箇条書き）をMarkdownの標準形式に変換する。
        3. テーブルをMarkdownのパイプテーブル（`|` 区切り）に変換する。
        4. ヘッダー・フッターの内容は文末にセクション分けして記載する。
      - **Excel (.xlsx)**:
        1. 各シート名を `## シート名: [名称]` の見出しとして出力する。
        2. 各行をCSV形式またはMarkdownのテーブル形式（`|` 区切り）に変換する。
        3. 複数シートがある場合は、シートごとに区切りを明示する。
        4. セル内の数式は計算結果（値）として出力する。
      - **PowerPoint (.pptx)**:
        1. スライド番号ごとに `## スライド N` の見出しを付与する。
        2. 各スライドの見出しと箇条書きテキストを抽出してMarkdown化する。
        3. ノート（発表者メモ）がある場合は、各スライドの末尾に `> ノート: ...` として含める。
   2. **フォールバック**: 特定のスライドやシートの読み取りに失敗した場合、「スライドN / シート『名称』の読み取りに失敗しました」と該当箇所を明示し、残りの変換結果を提供する。

3. **出力ファイルの生成と保存**
   1. 変換後のデータをVFS上の指定されたフォルダー（例: `/drive/` または `/`）に新しいファイル（`.md` や `.csv`）として保存、あるいはコードブロックで出力する。
   2. 出力ファイル名は元ファイル名をベースにする（例: `report.docx` → `report.md`）。
   3. 変換結果の概要（ページ数、シート数、スライド数、スキップされた要素等）をユーザーに報告する。

## Guidelines

### 基本ルール
- **バイナリ出力の非対応**: GeminiはOfficeファイル（`.docx`など）を直接バイナリ生成して出力することはできません。必ずテキストベースの出力（Markdown, CSV, Text）に留め、必要に応じてユーザーに説明してください。
- **データ構造の維持**: 見出しの階層（Word）や表の行列（Excel）が崩れないよう、マークダウン記法やCSVフォーマットを崩さず正確に変換してください。
- **画像のスキップ**: WordやPowerPoint内に埋め込まれている画像は変換対象外とし、「画像[名称]はスキップされました」などと明記してください。

### 入力バリデーションルール
- **ファイル拡張子チェック**: `.docx`, `.xlsx`, `.pptx` のみを対象とする。`.doc`, `.xls`, `.ppt`（旧形式）は対応を試みるが、精度の低下について警告する。
- **パスワード保護**: パスワード保護されたファイルは処理不可。「パスワードで保護されているため開けません。保護を解除して再アップロードしてください」と案内する。
- **ファイルサイズ**: 極端に大きなファイル（100ページ超のWord、100シート超のExcel）は部分変換を提案する。
- **マクロ付きファイル**: `.xlsm`, `.docm`, `.pptm` 等のマクロ付きファイルは、マクロ部分を無視してコンテンツのみを抽出する旨を通知する。

### 禁止事項
- Office形式（`.docx`, `.xlsx`, `.pptx`）への逆変換出力
- 元ファイルの内容の意図的な省略・改変（画像スキップ等の技術的制約を除く）
- ユーザーの指示なく出力形式を勝手に変更すること（例: CSV指定なのにMarkdownで出力）
- マクロやVBAコードの実行・再現

## Decision Examples

| # | ユーザー入力 | AIの判断 | 理由 |
|---|---|---|---|
| 1 | 「このWordファイルをMarkdownにして」 | スキル発火 → .docx 解析 → Markdown変換 → VFS保存 | Word→Markdownの明確な変換要求 |
| 2 | 「Excelの全シートをCSVにして」 | スキル発火 → 各シートを個別CSVとして出力 | Excel→CSVの変換要求。複数シートは個別ファイルとして処理 |
| 3 | 「パワポの内容をテキストで見せて」 | スキル発火 → スライドごとにテキスト抽出 → コードブロック表示 | PowerPoint→テキスト抽出の要求。ファイル保存ではなく画面表示 |
| 4 | 「このMarkdownをWordファイルにして」 | **発火しない** → 非対応の旨を説明 | Office形式への逆変換はバイナリ出力不可のため非対応 |
| 5 | 「Excelの売上データをMarkdownテーブルにして」 | スキル発火 → .xlsx 解析 → Markdownテーブル生成 | Excel→Markdownテーブルの変換要求。出力形式はMarkdown |

## Error Handling

| # | エラーケース | 検出方法 | 対処法 |
|---|---|---|---|
| 1 | ファイルが破損して読み取れない | パースエラー / ファイル構造が不正 | 「ファイルが破損している可能性があります。別のバージョンで再アップロードしてください」と案内 |
| 2 | 旧形式（.doc, .xls, .ppt）のアップロード | 拡張子チェック | 変換を試みつつ「旧形式のため変換精度が低下する可能性があります」と警告 |
| 3 | パスワード保護されたファイル | ファイルオープン時のエラー | 「パスワード保護されたファイルは処理できません。保護を解除して再度お試しください」と案内 |
| 4 | 特定シート/スライドの読み取り失敗 | 個別要素のパースエラー | 失敗箇所を明示し（「シート3の読み取りに失敗」）、読み取れた部分の結果を提供 |
| 5 | 画像のみのスライド（テキストなし） | テキスト抽出結果が空 | 「スライドNはテキストを含まないため（画像のみ）、スキップしました」と通知 |
| 6 | セル内の複雑な数式 | 数式パースの失敗 | 数式の代わりに「[数式]」というプレースホルダーを出力し、注記する |
| 7 | 出力形式の指定ミス（バイナリを要求） | 変換先拡張子がバイナリ形式 | 「この形式への変換は非対応です。代替としてMarkdown/CSV形式をお勧めします」と提案 |

## Data Structure

本スキルに特別なCanvas GUIはありませんが、VFSへの出力ファイル名と内容の紐付けは以下のように管理します：

```json
{
  "outputFilePath": "/[任意のフォルダ]/[元のファイル名].md",
  "content": "# 変換後のコンテンツ..."
}
```
