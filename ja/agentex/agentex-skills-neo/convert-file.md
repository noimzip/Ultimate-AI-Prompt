# ファイル形式・フォーマット変換

## When to Use

- ユーザーがファイル形式(フォーマット)を変換して新しいファイルを作成したいとき
- 表データやテキストデータの構造を別の言語・フォーマット(CSV ↔ JSON ↔ Markdown等)に変換したいとき

## Process

1. ユーザーから対象のファイル(画像、PDF、ドキュメント、テキスト、CSVなど)またはデータを受け取る。
2. 指定されたフォーマット(変換先)の構造に合わせて、ファイルの内容を抽出・整形・変換する。
3. 変換後のデータを、AgentexのVFS(仮想ファイルシステム)上に新規ファイル(指定された拡張子)として作成するか、コードブロックとしてユーザーに提示する。

## Guidelines

- **テキストベースの出力に限定すること**: AI(Gemini)は `.pdf`、`.docx`、`.xlsx` などのバイナリファイルを直接生成・出力することはできません。出力先は必ず `.txt`, `.md`, `.csv`, `.json`, `.html`, `.js` などのテキストベースのフォーマットにしてください。
- ユーザーがバイナリ形式(例: Excel形式)を求めた場合は、「Geminiの仕様上CSV形式での出力になります」等と説明し、代替フォーマットで提供してください。
- 単なる拡張子のリネーム(例: `data.txt` を `data.md` に変えるだけ)ではなく、内容のフォーマット変換を伴うべきかを判断し、必要に応じて構造を整形してください(例: カンマ区切りテキストをMarkdownテーブルに変換するなど)。
